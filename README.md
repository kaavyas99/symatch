# A matching decoder for bivariate bicycle codes

See our upcoming arxiv manuscript for details.

`` src `` has code to generate BB code objects and decode them using symatch and simplex-symatch (with and without BP). See the `` getting_started `` notebook for details.

`` code_pickles `` has pre-created BB codes stored as pickles of the object type GTCode (see ``src/gentoriccode.py``)
